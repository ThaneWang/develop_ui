# FW-V1 固件框架与 LVGL 模拟器 UI 对照

本工程为 **PC 端 LVGL 模拟器**，用于验证布局、手势与文案；**不承载**真实相机管线、编码器或存储驱动。下列对照说明 **文档章节** 与 **`src/ui`** 中已实现或占位的关系，便于后续按 `docs/firmware-fw-v1-framework.md` 迭代。

**原则**：UI 框架（页面划分、入口、设置分组、占位文案）以 **`firmware-fw-v1-framework.md`** 为 **产品能力大纲**（**FW-V1** 版本范围见该文档文首；正文无逐条版本号）。实现时按 **小步** 对齐，见 `.cursor/rules/rules.md`「迭代与变更」。

| 固件文档章节 | 当前模拟器对应（概要） |
|--------------|------------------------|
| **2.x 相机功能** | 主界面「模式页 / ISP / 预览提示」等为占位与手势演示；真实 3DGS、录像规格、2A、HDR 等 **未实现**，仅文档追踪。 |
| **2.3 / 3.2 预览与回放** | `ui_page_replay.c`：回放顶栏与正文占位；连续浏览等 **部分占位**。 |
| **3.3～3.7 文件与元数据** | 模拟器无真实文件系统；命名、目录、Metadata 以 **文档与后续固件** 为准。 |
| **4.2 首页与主界面** | `ui_page_main.c`：状态栏、预览区、底栏、模式显示/参数区；对齐 **4.2.1～4.2.3** 的文案与结构可随 FW-V1 条目增量更新。 |
| **4.3 模式切换** | 上滑进入模式页、底栏模式格等；**入口 / 反馈 / 参数继承** 需在规则与代码中逐项对齐 `firmware-fw-v1-framework.md`。 |
| **4.4 参数设置** | 控制中心 8 宫格 + **系统设置**子页：列表项对齐 **§6 系统管理**、**§5 连接与传输**（时间、开关机/休眠、电池、温控、存储卡、固件、日志、安全、蓝牙、Wi-Fi、USB、导出、设备信息、恢复出厂等）；点击 **仅占位打印**（`[Settings] tap …`）；列表 **固定剩余高度 + 纵向滚动**，滚动结束打印 **`[Settings] preview (center): …`**；列表滚动时 **不触发** 控制中心上滑关闭（见 `cc_sync_settings_list_geom` / `cc_settings_list_scroll_end_cb`）。 |
| **4.5 触控与按键** | 触控手势见 `.cursor/rules/ui_swipe_gestures.md`；实体键 **未模拟**（可后续用键盘映射占位）。 |
| **4.6～4.9 显示 / 灯 / 音 / 异常** | 部分在「系统设置」或占位 Label；指示灯、提示音、弹窗优先级 **按文档分批** 增加字符串与交互。 |
| **5.x 连接与传输** | 蓝牙 / Wi-Fi / App / C2 / 云端上传 / **USB（U 盘、充电、UAC/UVC）** / **文件导出** / **Webcam·直播** / **异常提示** 等 **未在模拟器实现真实协议**；**§5.2 蓝牙**：系统设置 → **蓝牙** 进入 **`ui_page_bt_settings`**（配对/重连动画、低功耗开关、Wi‑Fi 密码占位打印）；主屏右上角 **「蓝牙已开启」** 由 `ui_bt_state` + `UI_STR_BT_STATUS_ON` 控制。 |
| **6.x 系统管理** | 开关机 / 休眠唤醒 / 电池充电 / 温控 / 存储卡 / OTA / 日志 / 安全 / 时区等 **未在模拟器实现真实逻辑**；与 **控制中心「系统设置」**、状态栏电量等可 **分步** 对齐 **6.2～6.10**（占位文案与分组）。 |
| **7.x 配件协同** | 续航手柄、多机同步、触点、外接音频等 **无真实硬件**；后续若有配件相关 UI，对齐 **7.2～7.6**。 |
| **8.x 机内算法 / AI** | 增稳、鱼眼校正等与 **2.7** 等有交叉；AI / 语音 / 手势 / 人脸等 **仅占位**，对齐 **§8** 条目。 |
| **9.x 声音** | Mic / 扬声器 **无真实音频栈**；对齐 **9.1～9.2** 可做设置项与状态占位。 |
| **§10 菜单默认值** | 与 **下拉控制中心 / 快捷菜单**、**系统设置** 默认值策略对照；实现时与 **§4、§10** 一并迭代。 |
| **§11 附录** | sensor mode 表、microSD 列表等为 **工程/产品资料**；UI 侧可做「关于 / 帮助」或工程菜单占位，对齐 **11.1～11.2**。 |

**维护约定**：`firmware-fw-v1-framework.md` 增删条目后，本表与 `ui_i18n`、各 `ui_page_*` 的更新应在同一迭代或单独 PR 中说明范围，避免一次改动过大。
