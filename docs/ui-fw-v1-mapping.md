# FW-V1 固件框架与 LVGL 模拟器 UI 对照

本工程为 **PC 端 LVGL 模拟器**，用于验证布局、手势与文案；**不承载**真实相机管线、编码器或存储驱动。下列对照说明 **文档章节** 与 **`src/ui`** 中已实现或占位的关系，便于后续按 `docs/firmware-fw-v1-framework.md` 迭代。

**原则**：UI 框架（页面划分、入口、设置分组、占位文案）以 **`firmware-fw-v1-framework.md`** 为 **产品能力大纲**；实现时按 **小步** 对齐，见 `.cursor/rules/rules.md`「迭代与变更」。

| 固件文档章节 | 当前模拟器对应（概要） |
|--------------|------------------------|
| **2.x 相机功能** | 主界面「模式页 / ISP / 预览提示」等为占位与手势演示；真实 3DGS、录像规格、2A、HDR 等 **未实现**，仅文档追踪。 |
| **2.3 / 3.2 预览与回放** | `ui_page_replay.c`：回放顶栏与正文占位；连续浏览等 **部分占位**。 |
| **3.3～3.7 文件与元数据** | 模拟器无真实文件系统；命名、目录、Metadata 以 **文档与后续固件** 为准。 |
| **4.2 首页与主界面** | `ui_page_main.c`：状态栏、预览区、底栏、模式显示/参数区；对齐 **4.2.1～4.2.3** 的文案与结构可随 FW-V1 条目增量更新。 |
| **4.3 模式切换** | 上滑进入模式页、底栏模式格等；**入口 / 反馈 / 参数继承** 需在规则与代码中逐项对齐 `firmware-fw-v1-framework.md`。 |
| **4.4 参数设置** | 控制中心 8 宫格 + 系统设置子页；对应 **4.4.1 相机 / 4.4.2 系统** 的磁贴与列表可随导入扩展。 |
| **4.5 触控与按键** | 触控手势见 `.cursor/rules/ui_swipe_gestures.md`；实体键 **未模拟**（可后续用键盘映射占位）。 |
| **4.6～4.9 显示 / 灯 / 音 / 异常** | 部分在「系统设置」或占位 Label；指示灯、提示音、弹窗优先级 **按文档分批** 增加字符串与交互。 |
| **5.x 连接与传输** | 蓝牙 / Wi-Fi / App / C2 / 云端上传 等 **未在模拟器实现真实协议**；后续可增 **连接与传输** 子页或控制中心磁贴，条目对齐 **5.2～5.4**（配对、AP/Station、远程预览与控制、C2 联动、上传状态等）。 |

**维护约定**：`firmware-fw-v1-framework.md` 增删条目后，本表与 `ui_i18n`、各 `ui_page_*` 的更新应在同一迭代或单独 PR 中说明范围，避免一次改动过大。
