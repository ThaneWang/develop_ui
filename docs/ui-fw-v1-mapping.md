## 原则

本工程为 **PC 端 LVGL 模拟器**：验证布局、手势与文案；**不承载**真实相机管线、编码器或存储驱动。  
实现时以 **`firmware-fw-v1-framework.md`** 为产品大纲，**小步**对齐；流程约定见 **`.cursor/rules/rules.md`**「迭代与变更」。

## 固件章节 ↔ 模拟器 UI 对照表

| 固件文档章节 | 当前模拟器对应（概要） |
|--------------|------------------------|
| **2.x 相机功能** | 主界面模式页 / ISP / 预览提示等为占位与手势；真实 3DGS、录像规格、2A、HDR 等 **未实现**，仅文档追踪。 |
| **2.3 / 3.2 预览与回放** | `ui_page_replay.c`：回放顶栏与正文占位；连续浏览等 **部分占位**。 |
| **3.3～3.7 文件与元数据** | 无真实文件系统；命名、目录、Metadata 以 **文档与后续固件** 为准。 |
| **4.2 首页与主界面** | `ui_page_main.c`：状态栏、预览区、底栏、模式显示/参数区等；对齐 **4.2.1～4.2.3** 可随 FW-V1 增量更新。 |
| **4.3 模式切换** | 上滑模式页、快切等；**入口 / 反馈 / 参数继承** 逐项对齐固件文档。 |
| **4.4 参数设置** | 控制中心 8 宫格 + **系统设置**子页：列表项对齐 **§6**、**§5**；点击多 **占位日志**；列表 **固定高度 + 纵向滚动**，滚动结束预览日志；列表滚动与控制中心上滑关闭 **手势区分**（见 `cc_sync_settings_list_geom` / `cc_settings_list_scroll_end_cb`）。 |
| **4.5 触控与按键** | 触控见 **`.cursor/rules/ui_swipe_gestures.md`**；实体键 **未模拟**。 |
| **4.6～4.9 显示 / 灯 / 音 / 异常** | 部分在设置或占位 Label；指示灯、提示音、弹窗等 **按文档分批** 增加。 |
| **5.x 连接与传输** | 蓝牙 / Wi‑Fi / App / USB / 导出 / Webcam 等 **无真实协议**；**§5.2 蓝牙**：设置 → 蓝牙 → **`ui_page_bt_settings`**；主屏顶栏 **`UI_STR_BT_STATUS_ON`** 与 `ui_bt_state`。 |
| **6.x 系统管理** | 开关机、电池、温控、存储卡、OTA、日志、安全、时区等 **无真实逻辑**；与控制中心设置列表 **分步** 对齐占位文案。 |
| **7.x 配件协同** | 无真实硬件；后续配件 UI 对齐 **7.2～7.6**。 |
| **8.x 机内算法 / AI** | 与 **2.7** 等有交叉；AI / 语音 / 手势等 **占位**，对齐 **§8**。 |
| **9.x 声音** | 无真实音频栈；对齐 **9.1～9.2** 可做设置与状态占位。 |
| **§10 菜单默认值** | 与控制中心、系统设置默认值策略对照。 |
| **§11 附录** | 工程资料；UI 可做关于/帮助占位，对齐 **11.1～11.2**。 |
