## 2. 项目导入 LVGL，搭建 UI 框架

### 2.1 基础页面与信息架构

| 页面 | 说明 |
|------|------|
| 主页面 | 预览占位、顶栏/底栏、手势入口 |
| 回放 | 机内回放占位与返回 |
| 控制中心 | 下拉全屏、宫格磁贴、旋转详情等子页 |
| 系统设置 | 列表及详情子页（如蓝牙） |
| 模式切换 | 上滑模式页等 |
| 3A 页面 | 曝光/对焦/白平衡等（与固件 §2.6、ISP 对照） |

- **产品能力大纲**：**`docs/firmware-fw-v1-framework.md`**（FW-V1，文首版本说明）。
- **章节 ↔ 模拟器 UI 对照表**：**`docs/ui-fw-v1-mapping.md`**。
- **源码占位**：**`src/ui/pages/ui_page_*.c`** 等；CMake 见 **`docs/ui-simulator-status.md`** §3。

### 2.2 模拟器实现与优化状态

**详细清单（按页面、工程模块、已落实优化）见：`docs/ui-simulator-status.md`**。  
该文件替代本仓库历史上附在 `project-plan` 末尾的长列表，避免路线图与实现日志混在同一文件。

### 2.3 相机预览与 UI 分层（目标平台）

目标机：**视频走硬件 Overlay，LVGL 走 UI 层**；采集/编码与 UI 刷新解耦；录制由媒体子系统执行，UI 仅 **命令 + 状态**，且 **不在 LVGL 回调中阻塞** 编码与 IO。

**全文**：**`docs/ui-camera-preview-and-overlay.md`**（Mermaid 数据流、与 **`ui_hw_hal`** 衔接）。

## 3. 项目导入 RTOS 与平台能力

- **RTOS**：任务划分、与 UI 线程/消息机制对接。
- **文件系统**：媒体路径、配置与资源（对照固件 §3、§6）。
- **UI 资源**：位图/矢量与 LVGL 资源管理。
- **外设**：按键、传感器、连接等与 UI 同步（可先日志/HAL 占位，见 **`ui_hw_hal.c`**）。
- **固件升级**：流程与 UI 提示（固件 §6.7 等）。
- **字体**：目标机字库方案与裁剪。
